Tutoriel • Windows • Captures d'écran

Trouver la liste des composants de votre PC en quelques minutes

Pour vendre votre PC, faire évaluer une réparation ou vérifier ce qu'un upgrade peut donner, j'ai besoin de savoir ce qu'il y a dedans. Pas besoin d'ouvrir le boîtier ni d'installer quoi que ce soit : Windows a déjà un outil qui liste tout, et quelques captures d'écran suffisent.

  • Aucun logiciel à télécharger, tout est déjà dans Windows
  • 15 petites étapes, chacune montrée sur une image
  • Fonctionne sur un PC de bureau comme sur un portable
Commencer le tutoriel Où envoyer les captures
Publié le 16 septembre 2026 Windows 11 et Windows 10 Environ 3 minutes

Ce que vous aurez à la fin

Trois captures d'écran, parfois quatre ou cinq si la liste est longue.

Résumé système
Processeur, carte mère, quantité de mémoire et version de Windows.
Affichage
Le modèle exact de la carte graphique.
Disques
Chaque SSD et disque dur, avec son modèle et sa capacité.

1. Ouvrir Informations système

C'est l'outil qu'on appelle aussi msinfo32. Il est installé d'office sur tous les PC Windows.

  1. Cliquez sur le bouton Démarrer, le logo Windows dans la barre des tâches.
  2. Écrivez Informations système. La recherche démarre dès que vous tapez, pas besoin de cliquer dans la barre.
  3. Cliquez sur Informations système dans les résultats.

Raccourci pour ceux qui préfèrent le clavier : Windows + R, écrivez msinfo32 et faites Entrée. Le résultat est le même.

2. Capturer le Résumé système

La page qui s'ouvre par défaut contient déjà la plus grosse partie de l'information.

  1. Agrandissez la fenêtre avec le bouton carré en haut à droite. Sinon, les noms longs comme celui du processeur sont coupés.
  2. Faites une capture avec Windows + Impr. écran. L'écran s'assombrit une fraction de seconde : c'est le signe que la capture est enregistrée.

La touche peut s'appeler Impr. écran, Impr écr ou PrtSc selon le clavier. Sur plusieurs portables, il faut aussi tenir la touche Fn.

3. Capturer la carte graphique

Le Résumé système ne la montre pas, il faut aller la chercher dans les composants.

  1. Dans la colonne de gauche, cliquez sur le + à côté de Composants.
  2. Cliquez sur Affichage.
  3. Faites une capture avec Windows + Impr. écran. Si la liste dépasse la fenêtre, défilez vers le bas et refaites une capture.
Plus d'une carte dans la liste? C'est normal. Un processeur avec graphique intégré, un logiciel d'accès à distance ou un deuxième écran peuvent ajouter une entrée. Dans l'exemple, un adaptateur virtuel apparaît avant la vraie carte graphique. Capturez tout, je fais le tri.

4. Capturer les disques

Le type et la capacité du stockage comptent autant pour une vente que pour un diagnostic.

  1. Toujours sous Composants, cliquez sur le + à côté de Stockage.
  2. Cliquez sur Disques.
  3. Faites une capture avec Windows + Impr. écran. Chaque disque a son propre bloc : défilez et refaites une capture jusqu'à ce que tous les modèles soient visibles.

5. Retrouver les captures et me les envoyer

Windows range les captures dans un dossier précis. Ce raccourci l'ouvre directement.

  1. Appuyez sur Windows + R.
  2. Écrivez shell:screenshots.
  3. Cliquez sur OK. Le dossier Images, Captures d'écran s'ouvre.
  4. Envoyez les captures par courriel à raymondservicepc@outlook.com, en pièces jointes.

Le courriel est le plus simple depuis le PC, mais WhatsApp Web fonctionne aussi. Dans le courriel, dites-moi en une phrase si c'est pour une vente, une réparation ou un upgrade.

Si quelque chose bloque

Les petits imprévus qui reviennent le plus souvent.

Mon clavier n'a pas de touche Impr. écran

Sur plusieurs portables, il faut appuyer sur Fn en plus de Windows et Impr. écran. Sinon, Windows + Maj + S ouvre l'Outil Capture : sélectionnez la fenêtre, et sous Windows 11 l'image est aussi enregistrée automatiquement dans Images, Captures d'écran. Une photo de l'écran prise avec votre téléphone dépanne aussi, tant que le texte est lisible.

Mon Windows est en anglais

Cherchez System Information dans le menu Démarrer. Les sections à capturer sont System Summary, puis Components et Display, puis Components, Storage et Disks. Le raccourci shell:screenshots fonctionne de la même façon et ouvre Pictures, Screenshots.

Est-ce que les captures contiennent des informations personnelles?

Très peu. Le Résumé système affiche le nom de l'ordinateur et le nom d'utilisateur Windows, mais aucun mot de passe, aucun fichier et aucune donnée de compte. Vous pouvez masquer ces deux lignes si vous préférez, elles ne servent pas à l'évaluation.

Mon PC ne démarre plus

Le tutoriel ne peut pas se faire, mais des photos aident autant : l'intérieur du boîtier avec les pièces visibles, l'étiquette de la carte graphique et de l'alimentation, ou l'autocollant sous un portable avec le numéro de modèle. Une facture ou la fiche du fabricant fait aussi l'affaire.

Est-ce que ça fonctionne sur un portable?

Oui, Informations système est présent sur tous les PC Windows, portables compris. Ajoutez simplement le modèle exact, souvent inscrit sous l'appareil, parce qu'il permet de savoir ce qui est soudé et ce qui peut être remplacé.
